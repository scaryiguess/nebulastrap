NebulaStrap 3.1.1

Fixes the auto updater, which never actually applied anything in 3.1.0. It
downloaded the new build, checked it, put it aside - and then quietly did
nothing on quit. Three things were wrong, and each one hid the next:

- The helper script lived inside the folder the portable exe unpacks itself
  into, and that folder is deleted the moment the app closes. Its whole job is
  to wait for the app to close first. It is copied somewhere stable now.
- Handing it to PowerShell with a detached flag gave that process no console,
  and PowerShell cannot start without one. It died before running a line.
- Without the detached flag the helper is killed along with the app instead.
  The swap now goes through wscript, which needs no console and survives.

Every step writes to updates\swap.log now, so a swap that fails says why
instead of failing silently.

IF YOU ARE ON 3.1.0 you have to download this one by hand - 3.1.0 cannot
install it for you, that is the bug. From 3.1.1 on, updates apply themselves.

Reminders
- Windows will show a UAC prompt. Writing another process' memory needs it.
- SmartScreen will warn about an unsigned exe. More info, then Run anyway.
- The first Attach needs internet - the offset table is downloaded per Roblox build.
- If the app says the build does not match, do not turn Safe writes off to push past
  it. Pin your Roblox version with a strap, or wait for offsets for your build.
